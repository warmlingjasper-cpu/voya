# Voya — Accommodation Booking Platform

Voya is an accommodation booking platform inspired by Airbnb, developed with Python and Django.

The platform allows users to discover and book accommodations, while property owners can publish, manage, and monitor their own listings and reservations.

The project focuses on building a complete accommodation management experience, combining property discovery, reservation management, secure authentication, and host functionalities.

## Features

### Guest Experience

**User Authentication:** Secure user registration and login.
**Accommodation Search:** Search and explore available accommodations.
**Property Details:** View property descriptions, multiple images, and accommodation information.
**Reservations:** Book accommodations with availability validation and reservation management.

### Host Experience

**Property Management:** Create, edit, and manage accommodation listings.
**Multiple Image Uploads:** Upload and manage multiple images for each property.
**Reservation Management:** View and manage reservations associated with owned properties.
**Host Mode:** Dedicated property management experience for hosts.

### Backend & Security

**Django ORM:** Database models and relationships for users, properties, and reservations.
**Access Control:** Resource ownership validation and permission management.
**Server-Side Validation:** Validation of forms, reservation data, and file uploads.
**Web Security:** CSRF protection, secure cookies, HTTPS configuration, and environment variable management.
**Automated Tests:** Security tests covering unauthorized access, CSRF protection, excessive uploads, and invalid reservation values.

## Deployment
The application is deployed in a production environment using Render, with PostgreSQL for data persistence and Cloudinary for image storage and management.
Production configuration includes environment variables, static file management, HTTPS, and secure application settings.
